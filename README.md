# EPLcast

Predict Premier League top 10 standings and match results using Machine Learning (Random Forest).

## Overview

EPLcast uses historical match data to train a machine learning model that predicts match outcomes.  
It calculates team form from the last 3 matches and simulates upcoming seasons to generate predicted top 10 standings.  

- ML Model: Random Forest Classifier  
- Features: Team encoding, goal difference, recent form  
- Outputs: Match predictions & top 10 tables  
- Simulates: Next 5 EPL seasons
